# PitRelay Privacy Policy and Report Submission Terms

Public policy material for the PitRelay privacy website. This repository contains only the static policy page and its publishing files, not PitRelay product code, robot projects, logs or submitted reports.

The published policy is version 1.0, effective October 5, 2026. It covers the website, privacy correspondence and optional report submission terms. Report intake is not currently enabled; publishing the notice does not verify operational controls or open collection. There is no submission form, upload feature, analytics script or external asset dependency on this site.

`index.html` is the complete page and `.nojekyll` allows direct static hosting with GitHub Pages. No build step is needed.

Do not submit private information, code or reports through this repository's issues or pull requests. Privacy questions can be sent to pitrelay@gmail.com; do not email report packages while intake is unavailable. The policy records a 90-day maximum retention period and a 30-day verified deletion-request commitment. The report form, access controls, provider settings and deletion procedures must be verified before intake opens.
