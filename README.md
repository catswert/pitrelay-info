# PitRelay Privacy

Public policy material for the PitRelay privacy website. This repository contains only the static policy page and its publishing files, not PitRelay product code, robot projects, logs or submitted reports.

The policy is a draft, version 2026-10-05. Report collection is closed. There is no submission form, upload feature, analytics script or external asset dependency.

`index.html` is the complete page and `.nojekyll` allows direct static hosting with GitHub Pages. No build step is needed.

Do not submit private information, code or reports through this repository's issues or pull requests. A privacy contact has not yet been designated.
